# World Wonder Web

Milestone 001: local-only, self-contained archive interface. Open index.html in a modern browser. No build or dependencies required. This directory is intended for its own private GitHub repository named `world-wonder-web`.

## Implemented

- Responsive landing page and six proposed collection outlines.
- Search, collection dialogs, device-local saved subjects, membership proposal.
- Explicit preview and evidence status; no fabricated cases, miracle claims, statistics, or testimonials.
- Keyboard-accessible native dialogs and reduced-motion support.

## Not implemented

No verified article catalogue, accounts, subscriptions, server, actual paywall, payments, evidence uploads, or deployment. Client-side visibility is never sufficient to protect paid evidence.

## Next milestone

Select durable content storage and define source-backed record fields. Add an editorial review flow, then verified launch records. Before checkout, confirm provider acceptance of the precise content model, choose pricing, implement server-verified entitlements, and test billing webhooks. Restricted evidence needs a separate access model and review of rights, privacy, content eligibility, and provenance. For Wonder, label testimony and belief separately from documented findings.

## Development rules

Preserve working code. Verify existing progress before advancing. No deployments or spending without user approval. Working names need availability checks before branding investment. Aim for comprehensive worldwide coverage; do not claim world-leading size without evidence. Monetization is an objective, not a completed capability.
